# Live in the browser

Nostr is pure client-side — websockets plus WebCrypto, no server. So these demos
aren't sandboxes or recordings: they import the **real published `@nostragent`
packages** and talk to **real public relays**, right here on this page.

## A live feed

The component below is `new Pool().subscribe([...relays], [{ kinds: [1] }])` — the
actual library — streaming real notes as they arrive:

<div style={{ margin: '1.5rem 0' }}>
  <LiveFeed />
</div>

```tsx
import { Pool } from '@nostragent/pool'

const pool = new Pool()
for await (const note of pool.subscribe(['wss://relay.damus.io'], [{ kinds: [1], limit: 8 }])) {
  render(note)
}
```
