# @hopstr/nips — every NIP, tree-shakeable

One focused module per NIP: a typed factory + parser (+ an action where it
applies). Import the whole namespace or a single subpath — bundlers drop the rest.

```ts twoslash
// @noErrors
import * as nips from '@hopstr/nips'          // everything, namespaced
import { article } from '@hopstr/nips/nip23'   // just one NIP, tree-shaken
```

For the narrative intro (zaps end-to-end, the kind registry, the coverage test),
see the [NIPs guide](/guide/nips). This page is the module map.

## The kind registry

```ts twoslash
import { kindInfo, nipsWithKinds } from '@hopstr/nips/kinds'
// ---cut---
kindInfo(30023)        // { kind, nip, name, class, … }
//  ^?
```

- `kindInfo(kind)` — describe any kind
- `KIND_REGISTRY` — the full table
- `nipsWithKinds()` — which NIPs define kinds

Every entry in the canonical NIP index resolves to a module, a kernel-stack
feature, the registry, or an explicit parse-only note — and a meta-test asserts it.
